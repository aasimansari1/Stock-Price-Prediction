## ⚡ Overview

**Stock Price Prediction** uses machine learning to forecast stock prices based on historical data. Features multiple ML models, technical indicators, and visualization of predictions vs actuals.

---

## 🚀 Features

- Historical stock data fetching via `yfinance`
- Technical indicators: SMA, EMA, RSI, MACD, Bollinger Bands
- Multiple models: LSTM, Linear Regression, Random Forest
- Prediction vs actual visualization
- Configurable ticker symbols and date ranges

## ⚙️ Quick Start

```bash
# 1. Clone
git clone https://github.com/aasimansari1/Stock-Price-Prediction.git
cd Stock-Price-Prediction

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run prediction
python predict.py --ticker AAPL --days 30
```
